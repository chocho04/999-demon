# 999 Demon

A troll platformer in the spirit of Level Devil, designed level by level by Danik.

**Play:** https://chocho04.github.io/999-demon/

- 3 worlds × 15 levels, the 15th of each world is a long one
- Controls: ← → and Space, or the on-screen buttons on a phone
- Works offline once loaded; progress is saved in the browser
